# Team Timezone Map

Interactive team schedule visualization across time zones.

## Features

- 📊 Visual timeline grid with 24 hours in UTC reference
- ✏️ Real-time editing of team work windows
- 💾 Browser-persisted schedule data
- 🌍 Clear local schedule view for each team member

## How to use

1. Open `index.html` in a browser
2. Click a team member to edit their work window
3. Changes are saved automatically in the browser
4. Green cells represent working hours; orange indicates lunch

## Details

This project uses a 38.5-hour workweek rule, which equals 7.7 hours per day in a standard five-day workweek. The schedule reflects a 7.7-hour workday plus a one-hour lunch break for each member.
